# MysticAddon

Дополнение к плагину **MysticCore** (Minecraft 1.21.8, Purpur/Paper). Ничего в MysticCore не меняет — работает как отдельный jar.

## Что исправляет
1. **Спавн аирдропов**: вместо волны (3 шт. раз в минуту) — **1 сундук раз в 10 минут** (настраивается).
   Дополнение отключает штатный таймер MysticCore и запускает свой.
2. **"Пришёл по координатам — а сундука нет"**: watchdog каждые 10 секунд
   держит чанк с сундуком загруженным и **восстанавливает блок сундука**, если он пропал.
3. **Меню очистки памяти** (`/ma` или `/mysticaddon`, только OP):
   очистка дропа, убийство мобов, выгрузка чанков, GC, сохранение миров.

## Сборка
Запушь репозиторий на GitHub — workflow соберёт `MysticAddon.jar`,
скачаешь в Actions → Build → Artifacts. Положи в `plugins` рядом с MysticCore.jar.

## Настройка (config.yml)
- `drops.interval-minutes` — как часто спавнить аирдроп (по умолчанию 10).
- `drops.require-players-online` — не спавнить, когда никого нет на сервере.
- `watchdog.*` — проверка целостности сундуков.
- `menu.min-item-age-seconds` — возраст дропа для очистки.
